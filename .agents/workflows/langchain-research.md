# LangChain Research Workflow

Objective

Produce technically accurate answers about the LangChain ecosystem using official sources before generating code or explanations.

Steps

1. Determine whether the request involves:
   - LangChain
   - LangGraph
   - DeepAgents
   - LangSmith
  

2. Read the latest official documentation.

3. Search the official GitHub repository for implementation examples if documentation is insufficient.

4. Check whether the requested API is deprecated.

5. If multiple approaches exist:
   - recommend the modern approach
   - explain why it is preferred

6. Explain the architecture before writing code.

7. Generate production-quality code.

8. Explain:
   - design decisions
   - tradeoffs
   - common mistakes
   - alternatives

9. If documentation has changed recently, mention the version differences.

10. Never invent APIs.
If documentation is unclear, explicitly state the uncertainty instead of guessing.
